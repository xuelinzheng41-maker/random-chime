# Anew · 日新 (v2.0.0)

> **苟日新，日日新，又日新。**

**Anew（日新）** 是一款将 **全能待办工作台（TodoList / 四象限 / 看板 / 日历）**、**神经科学随机提示音专注舱（Gap Effect Focus Pod）** 与 **OpenAI 兼容 AI 助手** 深度融合的极简米白 / 夜间双主题 Windows 桌面应用。

---

## 核心模块与特性

### 1. 全能多视图待办工作台
- **智能清单与自定义分类**：内置 `☀️ 今日日新`、`📅 最近 7 天`、`📌 全部待办`、`📥 收集箱`、`✅ 已完成归档`，并支持无限创建自定义主题清单。
- **⊞ 四象限矩阵（艾森豪威尔矩阵）**：按 `P1 重要且紧急` / `P2 重要不紧急` / `P3 紧急不重要` / `P4 日常` 四象限直观管理核心要事，每个象限均支持内联快速添加与一键启动专注。
- **▥ 看板视图（Kanban）**：按 `待办 (Todo) → 进行中 (In Progress) → 已完成 (Done)` 可视化推进任务流。
- **🗓️ 日历月视图**：按月/日排期查看任务分布与每日累计专注时长，点击任意日期即可查看或新增当天日程。
- **右侧任务详情检查器**：支持子任务步骤清单（Checklist）、截止日期、优先级、预计时长、已投入专注统计与 Markdown 思考笔记。

### 2. 随机提示音专注舱（Gap Effect 核心组件）
- **任务一键联动专注**：在任意视图点击任务右侧的 `▶ 专注`，立即绑定该任务进入专注舱；专注画面上方直接展示该任务的子步骤供随时勾选。
- **全局迷你专注浮窗**：专注进行中切回清单、四象限或日历视图时，底部自动浮现迷你专注胶囊（实时倒计时、暂停/继续、提前结束、一键切回大屏时钟）。
- **点击倒计时切换 3 种时钟样式**：极简排版 / **3D 机械翻页时钟（Flip Clock）** / 禅意呼吸光环。
- **纯享沉浸全屏（`F11`）**：全屏下自动隐藏所有侧边栏与清单，满屏只留时钟；支持**鼠标滚轮自由缩放时钟大小（60%–170%）**，鼠标移动时底部优雅弹出悬浮控制栏。
- **90 分钟超日节律 + 3–5 分钟随机 10 秒闭眼微休息**：内置 Web Audio API 实时合成 **藏式颂钵 / 木质风铃 / 柔和钢琴 / 禅意木鱼** 及 **粉红雨声 / 40Hz 专注脉冲**；支持随时「提前结束」并将专注时长自动累加到对应待办任务。

### 3. OpenAI 兼容 AI 日新助手
- **通用接口兼容**：支持任意 OpenAI 兼容接口（中转站、DeepSeek、硅基流动、OpenAI、本地 Ollama 等），支持 `/v1`~`/v4` 路径自动识别与 `/models` 模型列表拉取及模糊搜索下拉。
- **✦ AI 一键拆解任务**：在快速添加栏或任务详情栏点击 `✦ AI 拆解`，自动将大目标拆解为 3–6 条可执行子任务步骤。
- **✦ AI 日新规划与专注复盘**：结合当前待办完成度、四象限优先级分布与随机提示音专注记录，一键生成每日/每周诊断与下一步行动建议。
