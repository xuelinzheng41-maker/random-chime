# 随机提示音 · Random Chime

一款基于神经科学 **间隙效应（Gap Effect）** 与 **超日节律（Ultradian Rhythm）** 设计的极简 Windows 桌面专注计时器。

在 90 分钟深度专注周期内，每隔 3–5 分钟随机响起柔和提示音，提醒你闭眼放空 10 秒，随后再次响起提示音恢复专注——既利用短暂清醒休息触发大脑快速神经重放，又通过随机间隔消除「盯倒计时」的分心焦虑。

---

## 核心特性

- **极简米白 & 夜间静谧双主题**：默认温润宣纸米白护眼风格，一键切换夜间暗色模式，自动记忆偏好。
- **点击倒计时切换 3 种时钟样式**：
  - **极简排版**：大号等宽数字 + 极细进度条；
  - **3D 机械翻页时钟（Flip Clock）**：带真实上下双半片 3D `rotateX` 翻页动画与机械折缝；
  - **禅意呼吸光环**：SVG 柔和圆环伴随呼吸微动。
- **沉浸全屏模式（`F11`）**：时钟自动等比放大，鼠标静止 3 秒后隐去多余控件。
- **随机微休息引擎**：默认 90 分钟专注 + 3–5 分钟随机间隔 + 10 秒闭眼呼吸倒数，所有参数均可自定义；默认隐藏下次提醒倒计时，保留随机期待感。
- **零外部依赖疗愈音效（Web Audio API）**：纯代码实时合成 **藏式颂钵 / 木质风铃 / 柔和钢琴 / 禅意木鱼**，区分「闭眼休息音」与「睁眼继续音」；可选叠加 **柔和粉红雨声 / 40 Hz 专注轻脉冲**（休息时自动柔和压低）。
- **专注目标与提前结束记录**：倒计时上方点击 `+` 即可填写本次专注目标；支持随时「提前结束」并精确记录实际专注时长、目标、微休息次数与复盘备注，持久化保存至专注历史。
- **AI 专注进展分析**：点击左上角标题或「AI 分析」进入设置面板，支持接入 DeepSeek / OpenAI / Kimi / 本地 Ollama 等 OpenAI 兼容接口（API Key 仅存本地），按今日 / 近 7 天 / 全部记录一键生成专属进展复盘与节奏建议。
- **桌面端专属能力**：无边框自定义标题栏、窗口置顶（Pin）、系统托盘后台静默计时、专注期间防系统休眠、本地今日专注与重放次数统计。

## 科学背景参考

- **10 秒清醒微休息与快速神经重放**：
  - Bönstrup et al. (2019), *A Rapid Form of Offline Consolidation in Skill Learning*, Current Biology ([DOI: 10.1016/j.cub.2019.02.049](https://doi.org/10.1016/j.cub.2019.02.049))
  - Buch et al. (2021), *Consolidation of human skill linked to waking hippocampo-neocortical replay*, Cell Reports ([DOI: 10.1016/j.celrep.2021.109193](https://doi.org/10.1016/j.celrep.2021.109193))
- **90 分钟超日节律**：人类清醒状态下注意力与警觉度的常见自然波动周期。

## 快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `Space` | 开始 / 暂停专注（微休息期间按下可跳过本次休息） |
| `V` | 切换时钟样式（极简 / 3D 翻页 / 呼吸光环） |
| `D` | 切换极简米白 / 夜间模式 |
| `F11` | 进入 / 退出沉浸全屏 |
| `R` | 重置当前计时 |
| `Esc` | 关闭设置面板 / 退出全屏 |

## 本地开发与构建

```bash
# 安装依赖
pnpm install

# 启动桌面应用
pnpm start

# 打包 Windows 免安装便携版 (.exe)
pnpm run build:win
```

打包产物位于 `dist/随机提示音-<version>.exe`。
